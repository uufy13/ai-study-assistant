# 机器学习基础（课堂讲义）

## 一、什么是机器学习

机器学习是让计算机从数据中学习规律、并据此做出预测或决策的方法。
与传统编程"人工编写规则"不同，机器学习是"从示例中自动学习规则"。

一个典型的机器学习任务包含三个要素：
- 数据（Data）：用于学习的样本集合；
- 模型（Model）：对数据规律的数学描述；
- 算法（Algorithm）：从数据中调整模型参数的步骤。

## 二、主要范式

### 监督学习
训练数据带有标签（正确答案），模型学习"输入 → 输出"的映射。
例如：根据房屋面积预测房价、根据邮件内容判断是否为垃圾邮件。

### 无监督学习
训练数据没有标签，模型自行发现数据的内在结构。
例如：把用户按消费习惯聚类、把文档按主题分组。

### 强化学习
通过与环境交互、根据奖励信号不断试错来学习策略。
例如：下棋、机器人控制。

## 三、训练与泛化

通常把数据划分为训练集和测试集：
- 训练集：用于调整模型参数；
- 测试集：用于评估模型在未见数据上的表现。

模型在训练集上表现好、但在测试集上表现差，称为过拟合（overfitting）；
模型在训练集上表现也很差，称为欠拟合（underfitting）。

## 四、常见算法

1. 线性回归：预测连续值，如房价；
2. 逻辑回归：二分类，如是否违约；
3. 决策树：可解释的树状规则；
4. 支持向量机：寻找最大间隔分类面；
5. 神经网络：多层非线性变换，适合图像、文本等复杂任务。
