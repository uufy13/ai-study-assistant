# input-machine-learning

## 摘要

机器学习是让计算机从数据中自动学习规律并做出预测的方法，核心三要素为数据、模型与算法。按训练信号可分为监督学习、无监督学习和强化学习三大范式。训练过程中需关注过拟合与欠拟合，并通过训练集/测试集划分来评估模型的泛化能力。

## 分级重点

### ⭐⭐⭐ 核心必考
- 机器学习的三个要素：数据、模型、算法
- 监督学习 vs 无监督学习的本质区别（有无标签）
- 过拟合与欠拟合的判断与含义

### ⭐⭐ 重要
- 训练集 / 测试集的划分目的
- 常见算法的适用场景（回归、分类、聚类、复杂任务）

### ⭐ 了解
- 强化学习的基本思想（环境交互 + 奖励信号）

## 关键概念

| 概念 | 解释 |
|---|---|
| 监督学习 | 数据带标签，学习「输入 → 输出」映射 |
| 无监督学习 | 数据无标签，发现内在结构 |
| 强化学习 | 通过环境交互与奖励信号试错学习 |
| 过拟合 | 训练好、测试差，泛化能力不足 |
| 欠拟合 | 训练、测试均表现差 |

## 常见算法速记

1. 线性回归 → 预测连续值
2. 逻辑回归 → 二分类
3. 决策树 → 可解释规则
4. 支持向量机 → 最大间隔分类
5. 神经网络 → 图像/文本等复杂任务
